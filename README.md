# IOT-Monitoring-system
##This project develops an IoT-based Real-Time Energy Monitoring and Management System to address the growing need for efficient energy consumption tracking and optimization in smart environments. 
##The system integrates simulated smart meters, MQTT for real-time communication, Firebase for data storage, and a Dash-based dashboard for visualization. Smart meters generate energy consumption data for various locations, which is transmitted via MQTT and visualized using interactive graphs, including real-time line charts, pie charts, and energy consumption forecasts powered by linear regression.

##Key features include anomaly detection, SMS alerts via Twilio for threshold breaches, and remote device control (e.g., turning off or restarting devices). An auto-save mode ensures energy efficiency by automatically disabling devices when consumption exceeds predefined thresholds. The system provides actionable insights into energy usage patterns, enabling proactive energy management in smart homes or buildings.
